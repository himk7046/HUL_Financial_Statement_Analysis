# HUL_Financial_Statement_Analysis
Five-year financial statement analysis of Hindustan Unilever (FY2020-21 to FY2024-25) in Excel: comparative, common-size and trend analysis, ratios, DuPont, Altman Z-score and Piotroski F-score, with recommendations for investors, suppliers, banks and management. MBA - BAI project, NFSU Gandhinagar.
